# Shenzhen Entropy Firefly — Free Website

This is a dependency-free static website made with HTML/CSS/JavaScript.

## Free deployment
1. Create a GitHub account.
2. Create a new repository named `entropy-firefly-website`.
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
4. In Cloudflare: Workers & Pages → Create application → Pages → Import an existing Git repository.
5. Select the GitHub repository and deploy.
6. Use the free `*.pages.dev` address.

## Before publishing
